这些数字如何统计？

输入 token 已包含缓存命中部分，不能再次相加。延迟来自已结束请求，P95 表示 95% 的请求不超过该耗时。没有数据时显示 —，不代表 0。正文从启用采集时开始记录，默认保留 7 天。
